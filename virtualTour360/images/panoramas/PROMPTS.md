# Sklentr 360° room prompts

Generate one 360° panorama per room with an AI 360 tool (for example Blockade Labs Skybox AI,
https://skybox.blockadelabs.com). Pick the most photorealistic style the tool offers
(for Skybox AI: a "Photoreal" / "Realistic" interior style).

**Export settings**
- Equirectangular, 2:1 ratio, the highest resolution available (8192 × 4096 ideal, 6144 × 3072 minimum)
- JPG, high quality
- Save each file in this folder with the exact file name shown, e.g. `01-reception.jpg`

The tour picks these files up automatically. A room without a panorama falls back to its normal photo.

**Use this negative prompt for every room** (if the tool has a negative prompt field):

> text, letters, words, logos, signage, watermark, people, person, faces, cartoon, illustration, painting, CGI look, low detail, blurry, distorted furniture, warped walls, duplicated objects, fisheye seams

No people and no text: AI tools draw both badly. The real Sklentr logo is added by the tour on top of the
blank feature wall described in prompt 01.

**Shared look (already included in each prompt):** premium creative-agency studio, matte charcoal walls,
warm oak slat panels, brushed brass details, polished concrete floor, warm 2700K lighting with a subtle
emerald-green accent glow, floor-to-ceiling windows with a city skyline at dusk.
